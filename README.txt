OBJECTION OFFLINE — офлайн-редактор сцен в стиле Ace Attorney
==============================================================
Версия: Release 1.1.2

ЧТО НОВОГО В RELEASE 1.1.2
--------------------------
• Проект с ресурсами одним файлом: Файл → «📦 Сохранить с ресурсами (ZIP —
  на другое устройство)…». В архив попадают проект и все его персонажи,
  фоны, музыка, звуки, текстбоксы, улики и картинки (по желанию — и
  стандартные ресурсы objection.lol). Архив можно переслать в Telegram и на
  телефоне открыть через «Файл → Открыть…» или «Открыть с помощью» —
  ресурсы сразу добавятся в библиотеку, ничего докачивать не нужно.
  Повторное открытие ресурсы не дублирует.
• Найти и заменить во всех кадрах: Ctrl+H (или Ctrl+F) и кнопка «⇄ Заменить»
  над списком кадров. Enter / F3 — следующее, «Заменить все» — одним шагом,
  Ctrl+Z отменяет. Теги [#…] по умолчанию не трогаются (например, при замене
  дефисов на тире).
• Стандартная музыка зацикливается бесшовно, как на objection.lol: точки
  петли берутся по файлу трека (раньше у 63 из 101 трека название не
  совпадало, и трек просто начинался сначала).
• В окне выбора музыки и звуков на каждой карточке есть ▶ — послушать перед
  тем, как добавить (раньше только правым щелчком, на телефоне никак).
• Текстбоксы: новый шрифт таблички (и текста) в копии текстбокса теперь
  применяется — раньше новый файл ложился под тем же именем, и оставался
  старый шрифт.
• Автометки: «(AJT based)», «(PWT style)» и подобное в названии дают метку
  игры.
• Картинки поверх сцены: галочка «Растянуть на весь кадр» — для рамок и
  интерфейсов во весь экран (например TikTok-интерфейс 435×845 в 9:16
  ложится ровно по кадру, без полос по бокам).
• Персонаж больше не пропадает из просмотра, если его картинку выгрузили из
  памяти (например, после правки персонажа в библиотеке): она загружается
  заново.
• Проверка обновлений и видеоуроки — с нового адреса репозитория
  github.com/Sandwich222/P.O.L.-Portative-Objection.lol-
• Версия для macOS больше не выпускается.

ЧТО БЫЛО В RELEASE 1.1.1
------------------------
• Кнопки «🌐 EN» / «🌐 RU» (язык интерфейса) и «?» (обучение) — в верхней
  полосе, рядом с «Смотреть с начала». Из меню «Файл» пункт языка убран.
  «?» показывает видеоуроки; их список берётся из репозитория программы на
  GitHub (файл tutorials.json), так что новые уроки появляются без новой

• При самом первом запуске язык выбирается по системе: русский для
  русскоязычных систем (и если русский есть среди языков системы), иначе
  английский. Дальше — как выбрано кнопкой.
• Музыка: «Плавно выключить» ([#bgmfo]), а потом «Плавно включить»
  ([#bgmfi]) в следующих кадрах снова возвращает ту же музыку — как на
  objection.lol. После плавного выключения музыка идёт дальше без звука.
  В экспорте видео — так же.
• Пары: кнопка «⧉» в настройках проекта (копия пары) и «⧉ Копия пары для
  этого кадра» в настройках кадра — та же пара отдельной копией, в которой
  можно поменять положения, не трогая другие кадры.
• Новые фильтры: «Виньетка» (с выбором цвета), «Зерно / шум» (зерно живое,
  меняется во время просмотра), «Размытие», «Радиальное размытие»,
  «Размытие по краям», «Резкость». Сочетаются с остальными фильтрами.
• Телефон: в библиотеке вкладки (Текстбоксы, Улики, Картинки) листаются
  вбок, а список ресурсов прокручивается вместе с панелями над ним.
• Телефон: «На весь экран» снова на весь экран (раньше картинка занимала
  треть высоты).

ЧТО БЫЛО В RELEASE 1.1.0
------------------------
• Несколько фильтров на один кадр: в разделе «Фильтр» настроек кадра —
  «＋ Ещё фильтр». Фильтры накладываются по порядку сверху вниз (↑ меняет
  порядок, ✕ убирает). У каждого свои «К чему» (фон, персонажи). Плавное
  наложение и снятие общие для всех фильтров кадра.
• Новые фильтры: «Контрастность» и «Насыщенность» (100 % — без изменений,
  0 % насыщенности — чёрно-белое, 200 % — вдвое ярче цвета), «Сепия +
  негатив» одним пунктом.
• Наложения: фильтр «Цвет с наложением» — заливка выбранным цветом в одном
  из 16 режимов (умножение, экран, перекрытие, мягкий свет, цветность
  и др.) с нужной непрозрачностью; действует только на выбранные слои
  и не выходит за контур персонажа. У своих картинок поверх сцены тоже
  есть «Режим наложения» (в библиотеке и отдельно для кадра).
• Проверка обновлений: Файл → «Проверить обновления…». При запуске
  проверка идёт сама не чаще раза в день (выключается в том же окне).
  Сведения берутся из раздела Releases репозитория
  github.com/Makasinc4ik/P.O.L.-Portative-Objection.lol- ; кнопка «Скачать»
  открывает файл именно для этой системы (Windows 64/32 бит, Linux, macOS,
  Android).
• На objection.lol этих возможностей нет: проверка совместимости при
  экспорте называет такие кадры (на сайте останется только первый фильтр).

ЧТО БЫЛО В RELEASE 1.0.0
------------------------
• Английский интерфейс: Файл → «🌐 English» (и обратно — «🌐 Русский»),
  а также кнопка в окне приветствия. Окно перезагружается, проект не
  теряется. Переводится всё, кроме содержимого проектов и названий ресурсов.
• Первый релиз. Архивы называются ObjectionOfflineWin64_Release1.0.0.zip
  и т. д., в шапке программы — «Release 1.0.0». Библиотека, сцены и
  настройки переносятся сами (не зависят от версии).
• Теги «в конце кадра»: [#evdhe] — убрать улику, [#bgmse] / [#bgmfoe] —
  выключить / плавно выключить музыку, [#bgsse] / [#bgsfoe] — остановить /
  плавно заглушить звуки. Срабатывают при переходе к следующему кадру, а не
  когда до тега дошёл текст: после текста нет лишней паузы без улики, и
  анимация позы следующего кадра не закрыта уликой. Пункты есть в меню
  «🔎 Улика», «🎵 Музыка», «🔊 Звук».
• Звуки: плавное появление и угасание (редактор звука в библиотеке).
  Угасание срабатывает в конце звука и при остановке звуков тегом.
  [#bgsfo] — плавно заглушить все звуки.
• Выбор файлов (спрайты, звуки, шрифты) — через системное окно, в котором
  есть «Все файлы» и учтены расширения в любом регистре (.PNG, .JFIF,
  .APNG, .AVIF, .BMP).
• Позы в паре — вкладками в разделе «Поза» настроек кадра: выбрать
  участника, щёлкнуть позу, и она сохранена (как на objection.lol).
  «Как в прошлый раз» — поза участника не меняется. Раньше позы остальных
  выбирались списками в разделе «Пара персонажей».
• Галочка «Говорят все в паре»: в этом кадре губами шевелят все участники
  пары. Без пары галочка неактивна.

• Размер текста и положение окна считаются от самой картинки текстбокса,
  а не от кадра. Текст всегда соразмерен окну в проекте любого формата,
  «сжатия» больше нет:
  – вертикальный текстбокс (картинка 9:16) в проекте 9:16 — во весь кадр;
  – вертикальный текстбокс в проекте 16:9 — по высоте кадра, по центру;
  – горизонтальный текстбокс с пустыми краями (сделанный «на оба формата»)
    в проекте 9:16 растягивается по высоте, пустые края обрезаются;
  – обычный горизонтальный текстбокс в 9:16 — по ширине кадра, как раньше.
• Текстбокс на всю высоту кадра не поднимается автоматически в 9:16
  (подъём остаётся для обычного горизонтального окна).
• Редактор текстбокса показывает предпросмотр в пропорциях самой картинки:
  вертикальный текстбокс редактируется и в горизонтальном проекте. Для
  вертикального предпросмотр стоит слева, настройки — справа и больше
  не перекрываются.
Кадры
• Ctrl+Z после удаления кадра работает (в том числе в русской раскладке).
• Правый клик по тегу в тексте реплики выделяет тег целиком.
• Вспышка своего цвета в теге: [#fmcFF0000] (как у цвета текста).
  Без кода — цвет из настроек проекта. В меню «⚡ Вспышка» есть пункты
  «свой цвет…».
• Файл → «Размер текста в списке кадров…» — крупнее или мельче шрифт реплик
  в левой панели (на видео не влияет, настройка общая для всех проектов).
• Замена имён: свой выпадающий список вместо системного — листается
  колесом, стрелки прокручивают список, Enter выбирает. Сверху — имена из
  этого проекта, ниже — вся библиотека.
• Пара: до 10 персонажей (на objection.lol видно только первых 5).
Широкие фоны
• Помощники (роль «консул») смотрят влево, как прокуроры, и теперь по
  умолчанию стоят у стойки обвинения. Другая стойка задаётся у кадра.
Библиотека
• Ctrl+Z отменяет последние действия в библиотеке: перенос в папку,
  удаление (файлы возвращаются), изменения ресурса. Работает до закрытия
  программы.
• Ctrl+клик по меткам и папкам слева сочетает их: показываются ресурсы,
  подходящие под все выбранные.
• Поле меток есть у всех текстбоксов, включая старые.
• Метки:
  – удалённая автометка больше не возвращается (повторное добавление снимает
    запрет);
  – HD-персонажи больше не получают метку DS;
  – «!Trilogy!» и подобные в восклицательных знаках распознаются.

Это аналог раздела Objection Maker с сайта objection.lol. Программа работает

ЗАПУСК
------
1. Распакуйте архив в любую папку, например на Рабочий стол или в «Документы».
   Не запускайте программу прямо из архива.
2. Запустите ObjectionOffline.exe.
   Если Windows покажет «Система Windows защитила ваш компьютер»,
   нажмите «Подробнее» → «Выполнить в любом случае». Программа не подписана
   цифровой подписью, поэтому Windows её не знает.

Все скачанные и добавленные ресурсы лежат в «Документы\Objection Offline\Library».
Чтобы перенести всё на другой компьютер, скопируйте эту папку и укажите её
в «Файл» → «Папка библиотеки…» → «Сменить папку…».
Переносная версия (например, на флешке): создайте рядом с ObjectionOffline.exe
пустой файл portable.txt — тогда библиотека будет в папке Library рядом с программой.

ПЕРВЫЕ ШАГИ
-----------
• Открыть проект с objection.lol: «Файл» → «Открыть…», выберите файл .objection.
  Программа сама предложит скачать персонажей, фоны, музыку и звуки этого проекта.
• Скачать стандартные ресурсы: «Библиотека» → «Стандартные с objection.lol».
  Это около 2–3 тысяч файлов, несколько сотен мегабайт. Сделайте это, пока сайт работает.
• Свой персонаж: «Библиотека» → «Персонажи» → «Добавить» → «Позы из файлов…».
  Подходят PNG, GIF и WebP, в том числе анимированные. Файлы с именами вида
  «Имя_idle» и «Имя_talk» сами склеятся в одну позу: «молчит» и «говорит».
• Своя музыка, звуки, фоны: вкладки библиотеки → «Из файлов…».
• Экспорт видео: красная кнопка «Экспорт видео». По умолчанию — быстрый способ
  (видеокарта). Если на компьютере он недоступен, видео запишется в реальном времени.

ZIP С ПЕРСОНАЖЕМ — КАК ЛУЧШЕ СЛОЖИТЬ ФАЙЛЫ
-------------------------------------------
Имя_персонажа/
    Стоит_idle.gif      ← молчит
    Стоит_talk.gif      ← говорит (также понимает «(a)/(b)», «_a/_b», «_stand/_speak»)
    Удар/idle.png       ← поза может лежать в своей папке
    Удар/talk.png
    Удар/pre.gif        ← анимация перед позой (длительность берётся из GIF/WebP)
    icon.png            ← значок
    blip.wav            ← голос
    Выкрики/objection.png и objection.mp3  ← выкрик со звуком
В одном архиве может быть несколько персонажей — каждый в своей папке.

ТЕГИ В ТЕКСТЕ (как на objection.lol)
-------------------------------------
[#p500]             пауза 500 мс
[#ts40]             скорость печати: 40 мс на букву (0 — мгновенно)
[#/r]текст[/#]      красный текст (g — зелёный, b — синий, cFFC700 — любой цвет)
[#fs] [#fm] [#fl]   вспышка: слабая, средняя, сильная
[#fmcFF0000]        вспышка своего цвета (буква c и hex-код; без кода — цвет из настроек проекта)
[#/i]…[/#]          курсив; [#/u] подчёркнутый, [#/s] зачёркнутый, [#/bd] жирный,
                    [#/sz150] размер в %; можно вместе с цветом: [#/bd r]…[/#]
[#ss] [#sm] [#sl]   тряска; [#sm600:quake] — тряска 600 мс типа «землетрясение»
[#bgm12]            включить музыку с номером 12
[#bgmfo]            плавно выключить музыку; [#bgms] — выключить сразу
[#bgs5]             звук с номером 5; [#bgss] — остановить звуки
[#evd3] [#evdi3]    улика 3 на весь экран / значком в углу; [#evdh] — убрать улику
Кнопки над текстом кадра вставляют эти теги сами.

ГОРЯЧИЕ КЛАВИШИ
---------------
Ctrl+S — сохранить, Ctrl+O — открыть, Ctrl+Z / Ctrl+Y — отменить / повторить,
P — проиграть с выбранного кадра, Esc — стоп, Пробел — дальше (в режиме «По клику»),
стрелки ↑ ↓ — переход между кадрами,
Ctrl+клик / Shift+клик по картинке кадра — выделить несколько; затем Ctrl+C, Ctrl+X,
Ctrl+V, Delete; Ctrl+A — выделить все кадры, Esc — снять выделение, F12 — консоль разработчика (для отчёта об ошибке).
